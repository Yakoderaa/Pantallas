# Intellectual property

## Copyright

Original Pantallas source code, documentation and visual assets are protected
by copyright from the moment they are created, subject to applicable law. The
repository uses a proprietary source-available license rather than an
open-source license.

## Branding

The Pantallas name and visual identity are reserved by the project owner. This
repository does not grant permission to rebrand or redistribute the
application.

## Patents

This repository does **not** claim that Pantallas is patented or patent
pending. Those phrases should only be used after an actual patent filing.

Software-related patentability and novelty rules vary by jurisdiction. Public
disclosure can affect patent rights in some countries, so any serious patent
strategy should be reviewed with a qualified patent professional before
further disclosure.

## Practical protection

For stronger commercial protection than a public source repository can offer,
a future structure can keep source development private while publishing only
signed installers and release metadata from a public distribution repository.
